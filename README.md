
# CrossApp
 проєкт з крос-платформного програмування

Предметна область: а. Склад. Сутності: Product (товар), StockBatch (партія), Warehouse (склад), Movement (переміщення). Призначення: облік залишків товарів по партіях.

## Запуск
dotnet build
dotnet run --project src/Cli

## Середовище
.NET SDK 8.0, Windows 10 x64
